ADD YOUR PHOTOS HERE
====================

1. Copy your image files into this folder (public/images/).
   Example file names: photo-1.jpg, beach.jpg, sunset.png ...

2. Open  src/data/gallery.js  and set the "src" of a photo to the file path:

       src: "/images/photo-1.jpg"

   (The path always starts with /images/ because this "public" folder
    is served from the site root.)

3. A photo with  src: null  shows a soft gradient placeholder instead —
   so the site looks complete even before you add real photos.

Tip: any common web image works (.jpg, .jpeg, .png, .webp, .avif, .gif).
